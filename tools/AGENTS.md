# AGENTS.md — tools

Developer tooling that is not part of the API runtime.

- `bruno/capital-care/` — Bruno API collection (plain-text `.bru` files) for the Category, Account and Transaction APIs and the monthly balance, with `DEV`, `PRD` and `CI` environments. The `build` job in CI runs the whole collection with the `CI` environment against the built image on an empty database (see [ci-cd.md](../docs/tech/definitions/ci-cd.md#pipeline)), so a request that breaks fails the pipeline.
- Requests run in numbered order (`seq`); `Categories/Errors/`, `Accounts/Errors/` and `Transactions/Errors/` cover 4xx responses and clean up the data they create. `Accounts/Errors/12 Create beyond the limit` fills `otherUserId`'s accounts to the system account limit (5 in DEV, 99 in PRD) with a script, then deletes them. `Transactions/` creates its own category and account first, walks create, list, edit, settle, undo and stop for a monthly, a one-off and an instalment transaction, then deletes everything it created (the category and account last). `Monthly balance/` creates its own account and two categories, then checks `GET /transactions/balance` and the `category`/`account` filters on that account only (so data already in DEV or PRD does not change the numbers): the carry-over from November to December, an empty month, the category rule (opens at 0, `totals` null), moving a one-off with `PATCH` `date`, shifting a monthly series, and the 400/401/409 answers; it deletes everything it created.
- Keep each request self-cleaning and its names unique per run, because PRD data persists.
- See [README.md](../README.md#api-collection-bruno) for how to open and run the collection.
